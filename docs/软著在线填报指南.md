# 软著在线填报指南

> 在线填报必须由你本人操作（需要实名账号）。这份文件把每一栏要填什么、传什么、注意什么列清楚，照着填即可。

---

## 一、入口与账号

1. 打开**中国版权保护中心**官网：`www.ccopyright.com.cn`
2. 进入「软件著作权登记」→「在线申报」
3. 注册个人账号并完成实名认证（手机号 + 人脸或银行卡）
4. 一个身份证号只能注册一个账号，注册后不可更换主体

**准备材料放一边**：身份证正反面照片、两个 PDF（见第三节）。

## 五、三处易错点

**1 · 首次发表日期别乱填**

推到公开仓库那一刻就算「已发表」。本项目 2026-11-19 首次公开推送，所以填 `2026-11-19`，**不能选「未发表」**——选了会和仓库的公开记录对不上，属于形式审查会问的点。

如果仓库已改为私有、且没有其他公开分发，才可选「未发表」。

**2 · 三个地方的名字必须一模一样**

表单「软件全称」、源程序页眉、说明书页眉，**逐字相同**，包括「25号」中间没有空格、没有「第」字。少一个字或多一个空格，都会被要求补正。

**3 · 源程序页数**

本项目 54 页，不足 60 页，按规则**提交全部**即可。不要为了凑 60 页去重复贴代码——重复内容会被认作材料不实。

## 六、提交后

- 保存受理号
- 补正通知一般通过站内信和邮件，注意查收
- 证书下发后，把电子证书存一份到 `docs/`，将来应用商店要传

---

## 七、如果被要求补正，通常是这三类

| 补正原因 | 处理 |
|---|---|
| 说明书与源程序的功能描述不一致 | 以说明书为准，改源程序页眉或说明书的名称表述 |
| 首次发表日期存疑 | 提供仓库公开记录截图 |
| 页数或行数不符 | 重新导出 PDF，确保 50 行/页 |
